# 🤖 Bai Memory Assistant (المساعد الذكي باي)

مشروع مساعد ذكي تفاعلي مبني بلغة **Python**، يتميز بقدرته على التفاعل الصوتي وحفظ الذاكرة واسترجاعها باستخدام ملفات **JSON**. يتعرف المساعد على المستخدم، يتذكر بياناته الشخصية (الاسم، العمر، الحالة المزاجية)، ويتفاعل معه صوتياً باستخدام مكتبة `gTTS`.

## ✨ ميزات المشروع
* **🧠 الذاكرة الدائمة:** حفظ واسترجاع بيانات المستخدم (الاسم، العمر، الحالة، وآخر طلب) باستخدام ملفات `JSON` لكي يتذكرك الروبوت في كل مرة تشغله فيها.
* **🔊 التفاعل الصوتي (Text-to-Speech):** تفعيل نطق الرسائل والنصوص صوتياً باللغة العربية باستخدام مكتبة `gTTS`.
* **🌷 رعاية الحالة المزاجية:** يتفاعل بذكاء مع حالة المستخدم (زين، تعبان، حزين، فرحان) ويقدم ردوداً مناسبة لكل حالة.
* **🧹 تنظيف النصوص:** دالة مخصصة لإزالة الرموز التعبيرية (Emojis) من النصوص الموجهة لمحرك الصوت لتفادي أي أخطاء في النطق.

---

## 🛠️ التقنيات المستخدمة
* **Python** (اللغة البرمجية الأساسية)
* **`json`** (لإدارة وحفظ الذاكرة محلياً)
* **`os`** (للتحقق من وجود ملفات الذاكرة)
* **`gTTS`** (Google Text-to-Speech لتوليد الصوت)
